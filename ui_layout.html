Auto-Analysis Pipeline — runs continuously for every enabled symbol

UPSTOX LIVE→ WATCHLIST FILTER (6 enabled)→ OPTION CHAIN ATM ±15→ ALL SYMBOLS → QLIB (batch, automatic)→ NORMAL STRATEGY + SMALL-PREMIUM STRATEGY→ STRIKE SELECTION→ RISK CHECK→ BUY CE / BUY PE / NO TRADE
Every cycle (default: every few seconds during market hours) the engine loops over all enabled watchlist symbols, fetches each ATM ±15 chain, stores it in SQLite and sends every symbol's data to Qlib automatically — no button press required. Results land in the Signal Board below and in per-symbol Trade Plans. Manual "Run Analysis" buttons exist only as an optional override.
