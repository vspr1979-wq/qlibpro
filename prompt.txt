# BUILD A SIMPLE WINDOWS 11 PYTHON OPTION-BUYING SIGNAL APPLICATION

Build a Python application for Windows 11 using Upstox and Microsoft QLib:

https://github.com/microsoft/qlib

IMPORTANT:

* NO CHARTS.
* NO TradingView.
* Data/table/card UI only.
* Option BUYING only.
* Signal generation only. Do NOT place live orders.
* Use real Upstox data.
* Use SQLite for persistence.
* Keep the UI simple with ONLY 4 pages.

5. TWO STRATEGY TYPES
=====================

The application must analyse TWO types of option-buying opportunities.

---

## A. NORMAL OPTION BUYING

Evaluate:

* ITM
* ATM
* Near OTM

Use:

* Underlying direction
* QLib analysis
* Momentum
* Volume
* OI
* Greeks
* IV
* Liquidity
* Spread
* Expected move
* Risk/reward

Do NOT automatically select ATM.

---

## B. SMALL-PREMIUM QUICK-MOVE

Also search for relatively low-premium options.

The purpose is to identify an option where a SMALL movement in premium can
produce meaningful profit when a suitably sized position is possible.

Example:

```
Buy premium = ₹10
Sell premium = ₹13
Move = ₹3
```

If quantity = 1,000:

```
Gross profit = ₹3 × 1,000
             = ₹3,000
```

This is only an example.

Calculate everything dynamically.

Do NOT simply choose the cheapest option.

Look for:

* Low premium
* High/abnormal activity
* High relative volume
* Last traded quantity
* OI increase
* Premium momentum
* Underlying momentum
* QLib confirmation
* Good liquidity
* Small spread
* Suitable Greeks
* Acceptable risk/reward

IMPORTANT:

High volume or high quantity alone does NOT mean BUY.

The system must confirm the direction using the underlying, QLib,
option behaviour and risk conditions.


Do not always select:

```

```

and do not always select:

```
Cheapest Premium
```

Select a candidate only when the complete strategy passes.

============================================================
7. PROFIT / RISK CALCULATION
============================

For every candidate calculate:

```
Entry
Target 1
Target 2
Target 3
Stop Loss
Lot Size
Number of Lots
Quantity
Capital Required
Maximum Loss
Expected Gross Profit
Estimated Charges
Expected Net Profit
Risk/Reward
```

Formula:

```
Profit =
    (Exit Premium - Entry Premium) × Quantity
```

Quantity must be a valid multiple of the contract lot size.

Do not exceed configured capital/risk limits.
